How to read it. Each row is a rule, numbered the usual way (Wolfram's). Each column is a ring of that many cells, joined end to end. A rule is played on every possible starting pattern at once. If all of them eventually go dark, the square holds a note, and the number is the length of the longest song. If even one pattern lights up forever, the square is a faint dot. Only the 64 rules that leave a dark neighbourhood dark and a fully lit one unlit can end at all, so those are all there is.

What it says. Almost nothing ends. Of the 64 rules, three end on every ring (0, 8, 64); one ends on every odd ring and never on an even one (32); three end exactly on rings whose size is a power of two (60, 90, 102); and a handful end on one or two small rings by accident and not again up to 20. Everything else hums forever somewhere.
